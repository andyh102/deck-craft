Deck Craft turns a plain-text Markdown file into a polished, self-contained HTML presentation — 31 slide types, four built-in visual themes, and an optional PowerPoint/PDF export. No server, no account, no dependency beyond Python 3's standard library.

One file in, one file out.

A deck is front matter plus one block per slide, separated by ---. Save it, run build.py, get a portable .html you can present from any browser.

deck.md
type: stats
title: Key Metrics
- $3.2M :: Annual Revenue :: +24% YoY
- 204 :: New Customers :: +73% vs Q1
- 74 :: NPS Score :: World-class
deck.html — rendered
Key Metrics
$3.2M
ANNUAL REVENUE
204
NEW CUSTOMERS
74
NPS SCORE

Four themes. One accent to override.

Set theme: in front matter and every token — palette, font, panels, the top bar — changes together. accent: and font: still override just those two on top.

Not a Claude plugin. A universal skill.

It's a folder: plain-English instructions in SKILL.md, and a builder that's pure Python standard library. Anything that can read a file and run Python can use it.

Claude Code — copy into ~/.claude/skills Cursor / Windsurf — open the folder, ask ChatGPT / Claude.ai — upload & ask or any other agent
the whole contract: can read text files + can run a Python 3 script.
no API keys · no accounts · no network calls · everything runs on your machine

Get it running.

Unzip, then build the worked example to see all 31 slide types, or start from the blank template.

$ unzip deck-craft.zip && cd deck-craft
$ python3 build.py example-deck.md # writes example-deck.html
$ open example-deck.html # or double-click it
