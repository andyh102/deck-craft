How it works

Three steps, no dashboard.

01 Describe

Tell your assistant what you need

Point Claude, Cursor, ChatGPT — any AI assistant that can read a file and run Python — at the DeckCraft folder and describe the deck.

02 Pick a style

Choose one of eight

Set theme: in the front matter, or let your assistant suggest one that fits the occasion.

03 Download

Get your deck.html

One portable file, ready to present. Export to PowerPoint or PDF straight from the deck if you need one.

Deck styles

Eight house styles.

Set theme: in front matter — scroll for all eight →
01 / Modern
Series A, one slide at a time
Archivo 600 / Archivo 400 · 8px grid
ModernOne accent blue, everything else greyscale. Left-aligned titles, no rules, no shadows.
02 / Professional
FY27 operating review
Spectral 600 / Libre Franklin 400 · footer rule
ProfessionalSerif headings, navy authority, thin gold rule under every title. Page numbers always on.
03 / Dark
Built for a dim room
Sora 600 / Sora 300 · #16181D cards
DarkNever pure black with pure white type. Cards lift with a lighter fill, not a shadow.
04 / Light
Say less, in more space
Libre Franklin 300 / 400 · 96px margins
LightNo colour at all. One idea per slide, huge margins, light weights only.
05 / Editorial
The case for buying less software
Instrument Serif / Spectral 400 · drop caps
EditorialMagazine logic: two-column body, pull quotes, italic captions. Titles can run three lines.
06 / Technical
p95 latency, by region
IBM Plex Mono 500 / Libre Franklin 400
TechnicalCharts are the slide. Mono labels, axis rules at 20% ink, amber reserved for the outlier.
07 / Bold
We grew 4× without a sales team
Archivo 900 / Archivo 500 · full-bleed
BoldType fills the frame edge to edge. Six words maximum. One slide, one colour flip.
08 / Warm
A bakery, three years in
Lora 600 / Sora 400 · 16px radii
WarmRounded corners, photography over flat colour, hand-set captions. Good for founder stories.

Universal

Not a Claude plugin. A skill.

It's a folder: plain-English instructions in SKILL.md, and a builder that's pure Python standard library. Anything that can read a file and run Python can use it.

Claude Code — copy into ~/.claude/skills Cursor / Windsurf — open the folder, ask ChatGPT / Claude.ai — upload & ask or any other agent
the whole contract: can read text files + can run a Python 3 script.
no API keys · no accounts · no network calls · everything runs on your machine
Kick-off prompt

One prompt to start.

Paste this into whichever assistant you pointed at the folder, fill in the brackets, and it'll draft a deck.md for you to review before building — see "Get it running" below for the raw commands.

Paste to your AI assistant 
Read SKILL.md in this folder, then build me a slide deck.

Topic: [what the deck is about]
Audience: [who it's for, and what they should do after]
Length: [tight ~8 slides, or a fuller ~14]
Style: [a theme name like modern or warm — or describe the mood]

Here's what I have so far:
[paste notes, a doc, or key numbers]
  1. 1Paste your raw material first — notes, a doc, data, a ticket. Richer input beats a short description; let the assistant structure it.
  2. 2Say who it's for and what they should do after — that decides the tone and which recipe (review, pitch, kickoff, retro) fits.
  3. 3Give real numbers, not placeholders — the assistant can't invent your KPIs, dates, or names.
  4. 4Name a rough length — “tight” or “fuller” is enough; open-ended briefs tend to sprawl.
  5. 5Describe the mood if you don't know a theme by name — “dark and techy” or “warm and personal” works as well as the theme id.
  6. 6Review the drafted deck.md before building — it's plain text, so tweaking it is faster than regenerating.
Get it running

Unzip. Build the example. Go.

$ unzip deck-craft.zip && cd deck-craft
$ python3 build.py example-deck.md # writes example-deck.html
$ open example-deck.html # or double-click it
